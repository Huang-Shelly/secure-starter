## 1. 系統描述與資料流

用文字或圖描述：使用者是誰、系統有哪些元件、資料怎麼流動、資料存在哪裡。

```
[瀏覽器] --HTTPS--> [CDN/WAF] --> [Next.js App] --> [PostgreSQL]
                                        |--> [Claude API]
                                        |--> [第三方服務：寄信 / 付款]
```

### 信任邊界

| 邊界 | 邊界兩側 | 跨越的資料 |
| --- | --- | --- |
| 網際網路 ↔ App | 匿名使用者 / 伺服器 | HTTP 請求、Cookie |
| App ↔ 資料庫 | 應用程式 / 資料層 | SQL（參數化） |
| App ↔ LLM | 我方 / 模型供應商 | 提示詞、工具結果 |
| LLM 輸出 ↔ 工具執行 | 不可信模型輸出 / 有權限的動作 | 工具呼叫參數 |

## 3. 攻擊者與攻擊面

| 攻擊者 | 動機 | 能力 |
| --- | --- | --- |
| 匿名網路攻擊者 | 竊資、勒索、濫用資源 | 自動化掃描、撞庫、已知 CVE |
| 惡意已登入使用者 | 存取他人資料、提升權限 | 修改請求、IDOR、商業邏輯濫用 |
| 外部內容投毒者 | 操控 AI Agent | 在網頁 / Email / 文件中植入指令 |
| 供應鏈攻擊者 | 植入後門 | 惡意套件、竄改 CI Action |
| 內部人員 / 被盜帳號 | 竊資 | 合法權限 |

攻擊面清單：所有 API 端點（見 `redteam/api/openapi.yaml`）、登入流程、檔案上傳、Webhook、AI 工具、管理介面、CI/CD。

## 4. STRIDE 分析

對每個元件 / 資料流逐項思考。風險 = 可能性（1–3）× 影響（1–3）；≥6 為高。

| # | 元件 / 流程 | STRIDE | 威脅描述 | 可能性 | 影響 | 風險 | 緩解措施 | 狀態 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| T1 | 登入 | **S**poofing 冒用 | 釣魚竊取密碼 | 3 | 3 | 9 | Passkey（抗釣魚，無密碼） | 已緩解 |
| T2 | Session | **S** | Session 被竊後重用 | 2 | 3 | 6 | HttpOnly、`__Host-`、短效、可撤銷 | 已緩解 |
| T3 | 筆記 API | **T**ampering 竄改 | 修改他人筆記（IDOR） | 2 | 3 | 6 | `ownedBy` 範圍化查詢 | 已緩解 |
| T4 | 高風險操作 | **R**epudiation 否認 | 使用者否認曾核准刪除 | 2 | 2 | 4 | 稽核日誌記錄核准者、時間、IP | 已緩解 |
| T5 | 錯誤處理 | **I**nformation disclosure 洩漏 | 錯誤訊息洩漏 SQL / 堆疊 | 2 | 2 | 4 | 統一錯誤格式、requestId | 已緩解 |
| T6 | 公開 API | **D**enial of service 阻斷 | 大量請求耗盡資源 / AI 費用 | 3 | 2 | 6 | 速率限制、大小限制、Agent 迭代上限 | 已緩解 |
| T7 | 授權 | **E**levation of privilege 提權 | 一般使用者呼叫管理功能 | 2 | 3 | 6 | 集中授權、預設拒絕 | 已緩解 |

## 5. AI / Agent 威脅（MITRE ATLAS + OWASP LLM Top 10）

| # | 威脅 | ATLAS 技術 | OWASP LLM | 情境 | 風險 | 緩解措施 | 狀態 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A1 | 間接 Prompt Injection | AML.T0051.001 | LLM01 | Email / 網頁內容要求 Agent 刪資料 | 高 | `wrapUntrusted` 隔離、白名單、高風險人工確認 | 已緩解 |
| A2 | 直接越獄 | AML.T0054 | LLM01 | 使用者誘導模型忽略規則 | 中 | 系統指令與權限分離（權限不靠提示詞） | 已緩解 |
| A3 | 敏感資訊外洩 | AML.T0057 | LLM02 | 模型輸出他人資料或金鑰 | 高 | 工具以使用者範圍化、輸出遮蔽 | 已緩解 |
| A4 | 過度代理 | — | LLM06 | Agent 擁有超出需要的工具 | 高 | 最小工具集、`risk` 分級、寫入次數上限 | 已緩解 |
| A5 | 系統提示洩漏 | AML.T0056 | LLM07 | 攻擊者取得系統指令 | 低 | 系統指令不放祕密；紅隊測試檢查 | 已緩解 |
| A6 | 不當輸出處理 | — | LLM05 | 模型輸出含惡意 Markdown / HTML | 中 | React 編碼輸出、移除外部圖片 | 已緩解 |
| A7 | 資源濫用 | AML.T0034 | LLM10 | 惡意請求耗盡 Token 費用 | 中 | 速率限制、迭代 / 呼叫上限、輸入長度上限 | 已緩解 |
| A8 | 資料 / 模型投毒 | AML.T0020 | LLM04 | RAG 資料被植入惡意內容 | | | |
| A9 | 供應鏈 | AML.T0010 | LLM03 | 第三方模型 / 套件被竄改 | | | |
